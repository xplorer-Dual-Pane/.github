# xplorer² — dual pane tabs with file search

xplorer² keeps one named board on the desk: the live dual panes, the search in front of you, and a short note the next person can read. Extra folder pairs wait for their own title.

## How xplorer² Sits

xplorer² does not replace a single Explorer window, the unlabeled search pile, or a commander pointed at folders you do not own. It sits beside them as a named commander desk for one job: which dual pane is live, which folder tabs still match file search, and what the next person should read on folders you own.

Each person on a shared PC keeps an xplorer² style of their own. Extra folder pairs wait for their own title instead of crowding the live panes.

A first visit should be one short dual-pane pass on folders you own, then the same xplorer² commander desk the next day. That is enough to see if the named commander session holds.

## Open Order

1. Open the last xplorer² commander desk, not a new empty dual pane.
2. Read the folder tabs and the last handoff.
3. Finish one visible file search inside xplorer² on folders you own.
4. Write what changed, then close with fewer unlabeled searches than you found.
5. If the panes feel crowded, drop anything that belongs to a different xplorer² pair, and keep the dual pane on folders you own.

## After a Week

A week in xplorer² is not a larger unlabeled search pile. It is the same title, a shorter live pane list, and a note that still makes sense before the next file search. Take finished tabs off the live set so the next visit starts on the commander desk that is still open.

Other programs stay where they are. xplorer² only keeps the path back: desk name, dual pane, folder tabs, handoff.

Leave xplorer² with a quieter commander desk than the one you opened. The next visit should start on that named commander session, not in a hunt.

## Field Note

xplorer² is easier to trust when the commander desk stays smaller than the unlabeled search pile it came from. Name the session, keep the live panes, finish one visible file search, and write what changed.

The same loop fits a home pair, a close-out, or a shared PC. Open the last xplorer² desk and continue. Do not point the commander at folders you do not own.
